# Miku Bot

**Sua assistente inteligente para Discord.**

Bem-vindo ao repositório oficial da Miku Bot!

A Miku é uma assistente inteligente desenvolvida para facilitar a administração de comunidades no Discord, utilizando inteligência artificial para compreender solicitações em linguagem natural.
